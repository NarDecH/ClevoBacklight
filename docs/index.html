01ฟีเจอร์ทั้งหมด

🎨 สีรายโซน + พาเลต

3 โซนอิสระ (ซ้าย/กลาง/ขวา), จานสี, พาเลต 12 สีคลิกเดียวทั้งแถบ, ความสว่าง 4 ระดับ, เอฟเฟกต์เฟิร์มแวร์ 7 โหมด + ความเร็ว 0–9

🎵 Music reactive

WASAPI loopback → FFT → BASS/MID/TREBLE แยกโซน, beat detector, sensitivity ปรับสดได้ระหว่างเล่น — ผ่านการทดสอบ end-to-end ด้วยโน้ตสังเคราะห์จริง

🖥️ Ambient (Ambilight)

DirectX screen capture → 3 แถบแนวตั้ง → gamma + smoothing → Mix ผสมกับสีที่เซฟ (ปรับสดได้)

🌡️ Temperature reactive (ใหม่ v1.6)

อ่านอุณหภูมิ CPU/GPU จาก EC RAM โดยตรง (ยืนยันข้ามแหล่งกับ Windows thermal zone แล้ว) → ไล่สี cyan → เขียว → เหลือง → แดง + กระพริบเตือน ≥90°C

🎛️ Color profiles (ใหม่ v1.6: จัดการใน GUI)

โปรไฟล์ตั้งชื่อได้ (gaming/work/night) สลับผ่าน GUI/tray/Ctrl+Alt+P/CLI — เพิ่ม/ลบ/เขียนทับทำใน GUI ได้แล้ว

🔋 Battery saver (ใหม่ v1.6)

ถอดปลั๊ก = ลดความสว่าง/เปลี่ยนโปรไฟล์อัตโนมัติ, เสียบกลับ = คืนค่าเดิม (daemon เช็กทุก 10 วิ)

🎹 Hotkey โหมดเรียลไทม์ (ใหม่ v1.7)

Ctrl+Alt+M โหมดเพลง / Ctrl+Alt+A Ambient สั่งผ่าน daemon ได้แม้โฟกัสอยู่ในเกม — ครั้งละหนึ่งเอนจิน เปิดตัวใหม่ = หยุดตัวเก่าให้เอง · ปรับค่าเริ่มต้นได้ในแผง Engine defaults

🩺 Health check (ใหม่ v1.7)

daemon ตรวจ EC + อุณหภูมิ CPU ทุก 60 วิ → เขียน status.json ให้เครื่องมืออื่นอ่าน + เมนู tray แสดง "EC OK, CPU °C" ย่อ ๆ

📊 Live Dashboard (ใหม่ v1.8)

daemon เปิดเว็บที่ 127.0.0.1:8787 — สถานะสด + กราฟอุณหภูมิย้อนหลัง + เอนจินที่รัน (เปิดจาก tray ได้)

🔔 Toast + 🧩 Hardware profiles (ใหม่ v1.8)

แจ้งเตือน Windows เมื่อ EC ล่ม/อุณหภูมิเกิน/เอนจินหยุดเอง · map เซ็นเซอร์ต่อรุ่น + --dump-ec --diff สำรวจเครื่องใหม่

🎮 Game auto-profile + ⏰ Schedule

เปิดเกม (foreground .exe) → สลับโปรไฟล์ทันที ปิดเกมกลับเอง · เปลี่ยนโปรไฟล์ตามเวลา ข้ามเที่ยงคืนได้

🎛️ รีโมตสลับโหมดเรียลไทม์ (ใหม่ v1.9.6, คุมไฟใหญ่ v1.9.12)

ปุ่ม music/ambient/temp บน Dashboard สั่ง daemon เข้าคิวเดียวกับ hotkey — เปลี่ยนโหมดจากมือถือได้ ปุ่มสลับ ▶/■ ตามสถานะจริง · เมื่อเปิด allow_control จะมีการ์ดไฟใหญ่แสดงสถานะจริง (แตะสลับเปิด/ปิด + สไลเดอร์ความสว่าง 0–3 + ปุ่มโปรไฟล์พร้อมไฮไลต์ตัวที่ใช้)

💬 Discord + ✈️ Telegram (ใหม่ v1.9.6–1.9.7)

แจ้งเตือนทุกชนิด (EC ล่ม/กลับมา, CPU ร้อน, พัดลมหยุด) + สรุปรายวันอัตโนมัติเข้าแชท — ตั้งค่าใน GUI หรือบนหน้าเว็บพร้อมปุ่มส่งข้อความทดสอบ

🗂️ Event log + 🩺 เกรดสุขภาพ (ใหม่ v1.9.8–1.9.7)

เหตุการณ์สำคัญทั้งหมดบันทึก JSONL (start/setting/engine/notify/update) ดู/filter/ดาวน์โหลดจากหน้าเว็บได้ · เกรดสุขภาพเครื่อง A–F สรุปจาก 30 วันล่าสุด

🔄 Auto-update (ใหม่ v1.9.8–1.9.10)

เช็ค GitHub release ทุก 6 ชม. (opt-in) เจอเวอร์ชันใหม่ → toast แจ้ง + ปุ่มดาวน์โหลดบน Dashboard — CI สร้าง release เองทั้ง zip + installer จาก tag

📱 เปิดจากมือถือ (ใหม่ v1.9.11)

โหมด LAN bind + token บังคับ — เปิด Dashboard จากมือถือในบ้านผ่าน QR (แผง Mobile access ใน GUI)

🔁 Daemon + hotkeys + tray

คืนค่าไฟหลัง boot/sleep/hotplug (ยืนยันจาก daemon.log แล้ว), global hotkeys ทุกปุ่ม, tray icon เปลี่ยนสีตามไฟจริง, single-instance guard

07โปรโตคอล EC (สั้น ๆ)

ถอดรหัสจาก DSDT ของเครื่อง (case 0x67 ของ SCMD) — mailbox ที่ EC RAM 0xF8–0xFC (FCMD/FDAT/FBUF/FBF1/FBF2) ผ่านพอร์ต ITE 0x62/0x66 ด้วยไดรเวอร์ WinRing0x64 (ลงนาม v1.2.0.5) — รายละเอียดเต็มใน README.md

ธุรกรรมถูกคุม 3 ชั้น: mutex ข้ามโปรเซส + retry ×3 (backoff) + drain OBF หลัง EC ประมวลผล FCMD จะเคลียร์กลับ 0x00 เอง = สัญญาณคำสั่งถูกรับ (ยืนยันบนเครื่องจริง) อุณหภูมิ: EC 0x07 = CPU, 0xC7 = GPU (field VGAT — แก้จากข้อสรุปเดิม 0x08 ซึ่งเป็น AC1 trip point) · พัดลม: DUT1/2 @ 0xCE/CF, RPM1/2 @ 0xD0/D2 (โหมด monitor อ่านอย่างเดียว — เขียน duty ถูก EC ทับกลับเสมอ พิสูจน์แล้ว v1.9.1; EC สะท้อน tachometer พัดลมเดียวไปทั้งสองช่อง v1.9.10)
